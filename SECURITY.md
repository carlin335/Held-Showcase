# Security policy

This repository contains public showcase materials only; Held's application source and provider implementation are maintained privately.

Please report a credible security issue privately to **Carlin Jon Soorenian** through the [carlin335 GitHub profile](https://github.com/carlin335) before publishing technical details.

Do not place API keys, tokens, certificates, private code, personal information, or exploit details in a public issue.

The current prototype is under active development. Scanner results and market information are research aids and are not guarantees of authenticity, grade, condition, or value.
